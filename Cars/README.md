# AutoElite - React E-Commerce Project

A modern car e-commerce homepage built using React and Vite.

## Features

* Responsive Navigation Bar
* Hero Section
* Categories Section
* Featured Cars Section
* Customer Testimonials
* Contact Section
* Footer

## Technologies Used

* React.js
* Vite
* JavaScript
* CSS3
* HTML5
